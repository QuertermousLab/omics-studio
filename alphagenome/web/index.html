How it works

      
    
        
  • Start loads the model on both GPUs (about 1–3 minutes). The page follows it and opens the Atlas
          when it is ready.
    • 
        
  • It stops by itself after an hour without predictions, and the GPUs are
          freed. Open Atlas pages do not keep it running; batch SNP predictions on the server do.
    • 
        
  • Stop frees the GPUs at once. If someone else used it in the last 10 minutes, or a batch job is
          running, only an administrator can stop it.
    • 
        
  • Human genome, GRCh38. Positions from hg19 tracks must be lifted over first. For research only:
          AlphaGenome's model terms do not allow clinical use.
