Omics Studio

The lab's genomics tools on THOR: Genome Canvas and GREAT for genomes and regions, Omics Canvas — the spatial, single-cell and CRISPR viewers — and Omics Workbench to download sequencing data and run the lab's pipelines on its servers. Each viewer keeps its own data, per workspace.
